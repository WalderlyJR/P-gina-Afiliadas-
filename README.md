# Plataforma de Ofertas e Produtos para Afiliados

Aplicação web desenvolvida para divulgação de produtos em promoção e geração de vendas por meio de links de afiliados.

A plataforma realiza integração com API externa para obtenção e exibição de produtos e ofertas, permitindo apresentar oportunidades de compra aos usuários de forma organizada e direcioná-los para a página de venda através dos links de afiliado.

## Sobre o Projeto

O projeto foi desenvolvido com o objetivo de criar uma plataforma de divulgação de ofertas para marketing de afiliados.

A aplicação consome dados de uma API externa para apresentar produtos em promoção, permitindo manter o catálogo de ofertas atualizado e reduzir a necessidade de cadastrar produtos manualmente.

Ao selecionar uma oferta, o usuário pode ser direcionado para a página correspondente do produto através do link de afiliado, possibilitando a geração de comissões sobre vendas realizadas.

## Funcionalidades

- Integração com API externa de produtos e ofertas
- Consumo e processamento de dados da API
- Exibição dinâmica de produtos em promoção
- Apresentação de informações e imagens dos produtos
- Organização das ofertas na interface
- Redirecionamento para páginas de venda através de links de afiliados
- Disponibilização de arquivos para download
- Interface responsiva para diferentes dispositivos
- Publicação da aplicação com domínio personalizado

## Integração com API

A aplicação realiza requisições para uma API externa responsável por fornecer informações sobre produtos e ofertas.

Os dados recebidos são processados pela aplicação e utilizados para atualizar dinamicamente os produtos apresentados na interface.

Esse processo permite trabalhar com informações provenientes de serviços externos e aplicar conceitos importantes de integração entre sistemas, consumo de APIs REST e manipulação de dados em formato JSON.

## Como Executar o Projeto

1. Clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Dependendo da configuração da API utilizada, pode ser necessário configurar credenciais ou parâmetros de acesso para carregar os produtos e ofertas.

## Segurança

Credenciais, tokens e chaves de APIs não devem ser armazenados diretamente no código-fonte público do projeto.

Para ambientes de produção, recomenda-se utilizar um serviço backend ou mecanismo seguro para gerenciamento das credenciais utilizadas na integração.
